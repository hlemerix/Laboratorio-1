## Requisitos
- PHP 7.0 o superior
- Servidor web (XAMPP, WAMP, etc.)

1. Clonar o descargar el repositorio
2. Colocar en la carpeta `www` de tu servidor
3. Acceder a través de `http://localhost/Practicas/`
